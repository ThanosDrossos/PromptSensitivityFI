## R1 — union-gold control arm · implementation notes (RESULT above)

**Code.** `prompt_sensitivity/scripts/rescore_union_gold.py` + `cluster/union_gold_arm.sbatch` + `tests/test_rescore_union_gold.py` (9 tests, passing).

**What it does.** Re-scores the existing generations against `SpecRow.all_answers` (the union of every interpretation's answers) at **both** levels, and reports

    Δ_target = Δ_union + Δ_targeting

`all_answers` was already computed by `build_levels.py` and is **identical at both levels** — verified by test — so the fixed-gold guardrail is satisfied exactly. This refutes the objection in `main_body.tex` that crediting any interpretation "would change the gold set between levels": it does not.

**It is a re-scoring job, not a re-run.** Every response is recovered from the SQLite cache by rebuilding the byte-identical `LLMRequest`; no eval model is loaded and no generation is issued. A cache miss is counted and the cell **skipped**, never silently regenerated.

**Enumeration verified against v3** (2026-08-07): at `--n-questions 150` the (question_id, spec_level) set matches `data/specificity_v3_*.parquet` **exactly** — 150/150 questions, zero difference either way, universe sizes identical (299 cells of 10 + 1 singleton).

**Cache status (resolved).** The cluster cache was intact; all 300 cells per model recovered and scored. The laptop-side probe (0 hits) correctly predicted the generations lived only on bwUniCluster.

## R2 — hierarchical ρ_F · DONE

**Code.** `prompt_sensitivity/analysis/rho_f_hierarchical.py` + `scripts/fit_rho_f_hierarchical.py` + tests. `metrics/` untouched.

**Model.** `y_i ~ Binomial(k, p_i)`, `p_i ~ Beta(mu_c, rho_c)`. For binary outcomes the beta-binomial overdispersion parameter **is** the ICC, so this estimates the same estimand as `rho_f` — with empirical-Bayes priors on **both** `rho` and `mu` fitted across all cells, and `rho_c` reported as a posterior mean + SD, defined everywhere.

**A modelling trap found and fixed.** Under a *flat* prior on `mu`, an all-wrong cell has marginal likelihood `1/(N+1)` at ρ=1 versus `1/(Nk+1)` at ρ=0 — a **9.2× pull toward ρ=1** at N=k=10. That would have scored the least informative cells as the *most* phrasing-sensitive. Fitting `mu`'s prior to the data removes it: in simulation, degenerate cells now land at **0.192** against informative cells' **0.195** (true 0.20), with honest wide posterior SD (0.161). There is a regression test for this.

**Validation.** Recovers known ρ: true 0.05/0.2/0.5 → 0.041/0.194/0.513. Agrees with MoM on cells where MoM exists (Spearman 0.64–0.72).

**Results on v3:**

| model | MoM (complete case) | coverage | hierarchical | σ²_B (absolute) |
|---|---|---|---|---|
| qwen_2_5_7b | 0.400 | 45.3 % | **0.487** | 0.0307 |
| mistral_7b_v03 | 0.233 | 57.3 % | **0.252** | 0.0226 |
| llama_3_1_8b | 0.128 | 66.0 % | **0.131** | 0.0143 |

**Two results this unlocks:**

1. **"ρ_F is correctly non-responsive to the specificity dial" is now actually supported.** On the full n = 150 (not the 36–70 cells that survived complete-case), Δρ_F = −0.002 / +0.013 / +0.013, Wilcoxon p = 0.98 / 0.22 / 0.49. Before, the claim was indistinguishable from being underpowered; now it is a properly powered null. **This strengthens the paper.**

2. **The absolute variance component σ²_B *does* rise with disambiguation**: +0.0105 (p = .059) / +0.0089 (p < .001) / +0.0089 (p = .019). Read carefully — at L0 accuracy sits near the floor (~0.2) so total available variance is small; as accuracy moves toward 0.5 the absolute phrasing variance grows *proportionally*, which is exactly why the **share** stays flat. Report both: the share is the level-invariant trait, σ²_B is the absolute quantity that is comparable **across models** (and it preserves the model ordering, which kills the "the ranking is just decoding entropy" objection).

## R3 — independence re-analysis · DONE

**Code.** `prompt_sensitivity/scripts/independence_analysis.py`. Outputs `data/independence_target.parquet` + `data/independence_target.md`.

**Protocol.** Every correlation **within (model × level)** — as `main_body.tex` already promises and the deck violated — under three estimators, with a **pre-stated** equivalence bound of |ρ| < 0.20 fixed before looking at the answers.

### Verdicts

| relation | primary (hierarchical, MI-pooled) | equivalence at \|ρ\|<0.2 | smallest bound supported | direction consistency |
|---|---|---|---|---|
| ρ_F vs **accuracy** | ≤ \|0.061\| | **NOT ESTABLISHED** | \|ρ\| < 0.42 | 5/6 positive, p = .22 |
| ρ_F vs **H_sem** | ≤ \|0.086\| | **NOT ESTABLISHED** | \|ρ\| < 0.33 | 4/6 positive, p = .69 |
| ρ_F vs **dispersion factor** | ≤ \|0.083\| | **NOT ESTABLISHED** | \|ρ\| < 0.45 | **6/6 positive, p = .031** |

### A correction to the review

**The imputed-0 counter-numbers in `REVIEW_2026-08-06_Adversarial.md` §2.3 (+.26/+.48/+.41) are an artifact and should not be used.** Degenerate cells are heavily skewed toward all-**wrong** rather than all-right (2.2:1 qwen, 6.8:1 llama, 4.8:1 mistral), and corr(is-degenerate, accuracy) = −0.21 / −0.34 / −0.38. Substituting a constant 0 therefore drops a spike of zeros at low accuracy and manufactures a positive correlation that is a property of the rule, not of the constructs. It is retained in the output table as a **sensitivity check only**, with that warning attached.

### What to claim now

The strong claim ("the three axes are statistically independent / orthogonal") **cannot be supported** and per the agreed decision rule should be **dropped**. What replaces it is defensible and still worth having:

> ρ_F is not detectably related to ability or to output dispersion: under the estimator that uses all cells and propagates per-cell uncertainty, every within-model, within-level association is below |0.09|. The sample supports equivalence only to |ρ| < 0.33–0.45, so we report bounds rather than independence. Among the cells where ρ_F is measurable at all, it shows a **consistent modest positive association with the dispersion family** (6/6 model × level combinations positive, sign test p = .031; disattenuated 0.15–0.42) — so ρ_F is *not* orthogonal to dispersion, and the previously reported .03 was the minimum over that family rather than a representative value.

**The three-axis structure survives as a measurement model** — no association exceeds ~0.09 under the primary estimator, and Horn's parallel analysis retains exactly three factors — but "orthogonal" must become "non-redundant, within these bounds".

**Reliability, honestly** (disjoint paraphrase halves, 200 splits, Spearman-Brown): qwen **0.380**, llama **0.520**, mistral **0.571**. The published .81/.92/.95 compares k=10 with a k=20 set that contains it.
