# Improve ICLR Appendix

An appendix supplies depth to the problem–gap–contribution–evidence–scope–significance chain; it cannot rescue an incomplete main-paper acceptance case. Preserve supplied scientific meaning, notation, citations, and local voice; use `write-iclr-2027-paper` for whole-paper consistency or current venue requirements.

## Input check

Identify diagnosis, revision, drafting, or planning. Obtain the main-paper claims, methods, results, and limitations; appendix units and intended support links; main-text references; and artifact/anonymity context. Name missing claim links or main-paper evidence rather than relocating decision-critical content by default.

## Acceptance-impact audit

1. For every appendix unit, state the main-paper claim, method, result, or limitation it supports, and ensure an explicit main-text reference.
2. Keep headline evidence, validity-critical protocol, central assumptions, core objective, comparison definitions, and material failure evidence in the main paper.
3. Use the appendix only after the main paper is judgeable: full proofs, exhaustive parameters, secondary robustness, extra examples, qualitative material, and implementation detail belong here when supportive.
4. Check hierarchy, stable notation, independent labels and cross-references, complete captions, and anonymous artifacts.
5. Flag main–appendix contradictions and decisive negative results hidden solely in supplementary material.

## Revise

Create a navigable support map and move only expanded detail into the appendix. Return essential methods, protocol, assumptions, primary evidence, and acceptance-changing failures to the main-paper evidence plan. Flag prose-incurable gaps—missing main-text evidence, absent references, or unexplained conflicts—for author evidence or judgment; never invent supporting experiments, proofs, or artifact details.

## Output

Return `Revised section` only when requested, followed by `Material changes`, `Evidence gaps`, and `Reviewer risks`.
